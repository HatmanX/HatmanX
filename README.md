## 🎮 Game Development — Godot Engine

> Desarrollo de videojuegos 2D de plataforma usando **Godot Engine** y su lenguaje nativo **GDScript**.

![Godot](https://img.shields.io/badge/Godot%20Engine-478CBF?style=flat-square&logo=godotengine&logoColor=white)
![GDScript](https://img.shields.io/badge/GDScript-478CBF?style=flat-square&logo=godotengine&logoColor=white)
![2D Games](https://img.shields.io/badge/Genre-Platformer%202D-478CBF?style=flat-square&logo=godotengine&logoColor=white)

| Área | Conocimientos |
|------|--------------|
| **Motor** | Godot Engine 4.x — escenas, nodos y señales |
| **Lenguaje** | GDScript — sintaxis similar a Python, tipado opcional |
| **Gameplay** | Mecánicas de plataforma: salto, gravedad, colisiones, movimiento |
| **Física** | CharacterBody2D, RigidBody2D, Area2D, TileMap |
| **Diseño** | Sprites, animaciones con AnimationPlayer y AnimatedSprite2D |
| **UI** | HUD, menús, pantallas de game over con Control nodes |
| **Audio** | AudioStreamPlayer, efectos de sonido y música de fondo |

```gdscript
# Ejemplo — Movimiento de plataforma en GDScript
extends CharacterBody2D

const SPEED    = 200.0
const JUMP_VEL = -400.0

func _physics_process(delta):
    if not is_on_floor():
        velocity += get_gravity() * delta
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VEL
    var dir = Input.get_axis("ui_left", "ui_right")
    velocity.x = dir * SPEED if dir else move_toward(velocity.x, 0, SPEED)
    move_and_slide()
```
